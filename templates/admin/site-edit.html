Analytics

An optional third-party tracker — Umami, Plausible, Fathom, GoatCounter. Leave the URL empty for none. The built-in counter on the Dashboard keeps running either way, and covers visitors, referring sites, places and reading time without a cookie — a tracker adds identity across devices, which is the part this deliberately does not do.

Rendered as data-* on the script tag: Umami wants website-id, Plausible domain, Fathom site. The script's origin is added to the site's Content-Security-Policy automatically — without that the browser would refuse to run it.

RSS feeds are managed on the Links page. Nav and social links are below.
