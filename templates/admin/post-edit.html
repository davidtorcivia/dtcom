Drag an image in, or paste one, to upload it — the cursor lands in the ![] brackets so you can type a caption straight away. An image on its own line renders with that caption beneath it. Ctrl/⌘+S saves.

For a figure that changes with the theme, press Light/dark pair and select both files at once — filenames containing light and dark are sorted out for you, and the status line says which went where. It writes both lines into one paragraph, which is what makes them a single swapping figure; the caption on the first covers both:
![The transfer function](/images/fig-light.png#light)
![](/images/fig-dark.png#dark)

Select text, then: Ctrl/⌘+B bold · I italic · E code · K link · Shift+X strikethrough · Shift+H highlight · Alt+1–6 heading. Pressing again removes it.

In a list, Enter starts the next item and Tab/Shift+Tab nests it; Enter on an empty item steps back out. Shift+Enter is a plain newline. Saving keeps you in the post, and unsaved changes are held in this browser until they are.
